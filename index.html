HTML

HTML (HyperText Markup Language) — это язык разметки, с помощью которого создаются веб-страницы. Он описывает структуру содержимого на странице: где будет текст, заголовки, изображения, ссылки и другие элементы. Браузеры читают HTML и отображают его как визуальный веб-сайт.

HTML Пример:


  <!DOCTYPE html>
  <html>
    <head>
      <title>HTML Tutorial</title>
    </head>
    <body>
      <h1>This is a heading</h1>
      <p>This is a paragraph.</p>
    </body>
  </html>

CSS

CSS (Cascading Style Sheets) — это язык таблиц стилей, который используется для оформления веб-страниц. С его помощью задаются цвета, шрифты, отступы, расположение элементов и другие визуальные параметры. Если HTML отвечает за структуру страницы, то CSS — за её внешний вид.

CSS Пример:


  body {
    background-color: lightblue;
  }
  
  h1 {
    color: white;
    text-align: center;
  }
  
  p {
    font-family: verdana;
  }
